# P833 Call Receiver: After-Action Record

By Ethan Brady & Ryan Raikes

## Decisions

| # | Date | Decision | Why |
|---|---|---|---|
| D1 | 11 Nov 2026 | The receiver runs on an AlmaLinux laptop, not the Pi. | User's choice. |
| D2 | 11 Nov 2026 | Each cell has a Waveshare ESP32-S3-ETH-8DI-8RO board, connected over Wi-Fi to an isolated IoT network. | User's choice. The board's Ethernet is unused. |
| D3 | 11 Nov 2026 | Board to laptop is HTTP POST with JSON and a shared key. The board resends until it gets "OK", and the laptop drops repeats. | Simple to build and test. Wi-Fi can drop a message, so the reply tells the board the call landed. |
| D4 | 11 Nov 2026 | Repeats are dropped by board, boot and sequence number (10 min), and by board, code and press (15 s). | Board retries and board restarts must never double-page. |
| D5 | 11 Nov 2026 | Pages are spoken on the Norstar through laptop, SIP, Grandstream HT813 FXO port, Nortel ATA2, Norstar. | User's phone path. The ATA2 expects a phone, so it needs the HT813's FXO port. |
| D6 | 11 Nov 2026 | All codes page the floor zone. The office zone is set up but unused. | User's choice. |
| D7 | 11 Nov 2026 | Pages play English, then Spanish. Codes 2 to 6 say "<Who> needed at press N." Press 0 says "Press number unknown." | User's choice. Codes 7 to 9 use the wording from the PLC brief. |
| D8 | 11 Nov 2026 | Python using only its standard library (3.6+), as a systemd service with restart. Only port 8833/tcp is opened, and SELinux stays on. | Nothing to download on an isolated laptop. Follows the standing rules. |
| D9 | 11 Nov 2026 | Dry run is on by default. The receiver refuses to start with dry run off until the phone step exists. | No real page goes out before the user says so. |
| D10 | 11 Nov 2026 | Calls from an unknown board ID are still paged, with a warning. | A misconfigured board must not lose a real call. The key still blocks strangers. |
| D11 | 11 Nov 2026 | No change on the PLC side. | The receiver only uses what the board sends. |
| D12 | 11 Nov 2026 | Admin page (`/admin`) for test calls, custom pages, adding, renaming and removing boards, and the dry-run switch. The status page stays open and read-only. | User request. |
| D13 | 11 Nov 2026 | The admin page needs a password (HTTP Basic), kept in the root-only `secrets.env`. Forms posted from other web sites are refused. | Anyone on the IoT network could otherwise page the floor or change boards. Plain HTTP is acceptable on the isolated network only. |
| D14 | 11 Nov 2026 | The board list and dry-run switch are saved in `/var/lib/p833-receiver`, not the config. The config gives first-time defaults only. | The service can't write `/etc`, and settings changed on the page must survive restarts and updates. |
| D15 | 11 Nov 2026 | With dry run off and no phone step built, pages are logged FAILED instead of the receiver refusing to start. | The switch has to work from the page; failing loudly never hides a lost page. |
| D16 | 11 Nov 2026 | `install.sh` handles both first setup and updates; `update.sh` pulls from GitHub and then runs it. | User request. Every run backs up first and keeps the config, secrets, board list and log. |
| D17 | 11 Nov 2026 | All pages now say "<Who> requested to press N", including codes 7 to 9 ("Maintenance requested to press N for camera fault"). Spanish: "Se solicita ... en la prensa N". Press 0: "<Who> requested. Press number unknown." Replaces D7's "needed at" and the PLC brief's "required at". | User's choice. |
| D18 | 11 Nov 2026 | On update, the installer (`install/migrate_config.py`) replaces page text in the laptop's config only where it is still an old default, and adds new settings. Hand-edited text and the dial digits are kept. | So wording changes reach the laptop without losing local edits. The old config is backed up first. |
| D19 | 11 Nov 2026 | Page audio is recorded ahead of time with the Piper offline voices (en_US-lessac-medium, es_MX-claude-high), in pieces plus the numbers 1 to 999, and joined at page time: chime, English, Spanish, played twice. | No speech program or internet needed on the laptop; natural voice. |
| D20 | 11 Nov 2026 | The clips are made in the build session and pushed to the repository (user's choice). | User's choice. |
| D21 | 11 Nov 2026 | A live page with a missing clip fails (FAILED, "no audio"); a clip whose text no longer matches the config still plays, with a warning on the admin page. | A silent page is useless and must show as failed; old wording is better than none. |
| D22 | 11 Nov 2026 | The phone settings are editable on the admin page: HT813 address and ports, dial method, waits, tone timing, each zone's dial digits, code-to-zone, chime and times played. They are saved in `/var/lib/p833-receiver/settings.json` on top of the config, with a Reset button. | User request: tune the dial code and timing on site without editing files. |
| D23 | 11 Nov 2026 | Dial digits use 0-9 * #, a comma for a half-second pause and F for a hook flash (the ATA2's Link). Default dial method is 2-stage: the HT813 picks up and the laptop sends the digits as tones. | An analog line on an ATA2 likely needs a flash or a feature code; 2-stage lets us send pauses and flashes. |
| D24 | 11 Nov 2026 | Each number is recorded together with the words all messages share before it ("requested to press 27", "en la prensa 27"); the message clip is only the start ("Maintenance"). Pieces are joined with a 40 ms pause. | A machine check (Whisper) misheard numbers recorded on their own ("three", "seis", "seiscientos"); with this split every press number checked came out right. |
| D25 | 11 Nov 2026 | Pronunciation fixes for the voices live in `tools/make_audio.py` (`PRONOUNCE`); the Spanish voice says "Red Rábit". | The Spanish voice read "Red Rabbit" as Spanish words. |
| D26 | 11 Nov 2026 | The 2,036 clips (about 66 MB, 8 kHz 16-bit WAV) are committed to the repository. | User's choice (D20). Every re-recording adds about 66 MB to the git history, so re-record only when wording changes. |
| D27 | 11 Nov 2026 | Voices: English en_US-hfc_female-medium (sample D), Spanish es_MX-claude-high (kept). | User's choice from the samples. |
| D28 | 11 Nov 2026 | Only presses 1 to 100 are recorded (about 250 files, 7 MB, down from 2,036 files, 66 MB). A press above 100 pages as "press number unknown", with a note. | User's choice. A page with the wrong number would be worse than one that says it's unknown. |
| D29 | 11 Nov 2026 | Each department has its own tone, from the user's andon tones (phone versions): maintenance bell (2, 8, 9), technician wood (3), supervisor glide (4, 7), quality flute (5), packaging pluck (6). The tone plays before each play of the message; once, twice or off, and per-code choice, on the admin page. | User request. The tones are kept as supplied (about 4 dB quieter than the speech). |
| D30 | 11 Nov 2026 | Preview on the admin page shows the exact words and plays the exact audio of a test call before it is sent; it sends and logs nothing. | User request: hear the message before sending it. |
| D31 | 11 Nov 2026 | Every page starts with 2.5 s of silence (adjustable 0 to 10 s on the admin page). | User request: the paging system must not miss the beginning of the message. |
| D32 | 11 Nov 2026 | The start of the message and the press number are recorded as one phrase per department ("Maintenance requested to press 27"): 1,000 clips for presses 1 to 100 in two languages, 1,033 files and 45 MB in total. Supersedes the shared number clips of D24. | The user heard "Maintenance" as a different voice: recorded alone, the word was said as a finished statement, about 10% lower in pitch. The user chose this over the smaller set. |
| D33 | 11 Nov 2026 | Pages say "press number N": "Maintenance requested to press number 27." / "Se solicita mantenimiento en la prensa número 27." The department phrase ending in "press number" is one recording per department; the number (1 to 100) is a separate recording shared by all departments, after a 120 ms pause. 243 files, 5 MB. Supersedes D32. The installer updates the old "requested to press" wording in the laptop's config. | User's design. In the machine check every press 1 to 100 came out right in English; in Spanish, 78 was once heard as 68 (correct on re-test). In English the number starts higher in pitch than the end of "press number", so it sounds like a separate announcement. |
| D34 | 11 Nov 2026 | Board firmware (`firmware/`, v1.0.0): one Arduino sketch for every board. DI1 is read every 1 ms in its own task, pulses are decoded per the brief (±40 ms), calls are queued (10) and resent until the laptop answers OK, with a heartbeat every 60 s. Settings (ID, Wi-Fi, server, key, IP, input) are set over USB and kept in flash. | Reliable over Wi-Fi; one image for all boards; no laptop or PLC change needed. |
| D35 | 11 Nov 2026 | Board facts from Waveshare's wiki and demo code: DI1 = GPIO4, input reads LOW when energised (pull-up on), WS2812 LED on GPIO38, buzzer on GPIO46, power 7 to 36 V, esp32 core 3.0+. Wiring: PLC OUT14 to DI1, PLC 0 V to COM (PNP/sourcing, per Waveshare's sister Modbus 8-channel module, which has the same terminals), DGND unused. Board power from a 24 V that stays on through the e-stop. | The user allowed waveshare.com. The COM wiring is confirmed on the bench with `watch`. |
| D36 | 11 Nov 2026 | Status LED (green OK, blue pulses, yellow call waiting, red error) and a buzzer chirp when a call is decoded (`beep off` to silence). | Lets someone at the cell see the board got the call without a laptop. |
| D37 | 11 Nov 2026 | Tested without hardware: the decoder on a PC (1,240 messages and edge cases), and the whole firmware on a PC against the real receiver (retry while the receiver is down, Wi-Fi drop, partial message, heartbeat). Not yet compiled with the real ESP32 tools; their download is blocked in the build session. | The first Arduino IDE upload is the remaining compile check. |
| D38 | 11 Nov 2026 | Board firmware 1.1.0: network updates from a browser at `http://<board IP>/update`, behind a password set over USB (`otapass`; off until set), plus a status page at `/`. Refused while a call is waiting to be sent. Partition scheme "Minimal SPIFFS (1.9MB APP with OTA)". The board stays on Wi-Fi only. | User's choice: no cable needed for later updates. Wi-Fi only, as chosen; the Ethernet port is unused. |
| D39 | 11 Nov 2026 | Board firmware 1.1.1: the Wi-Fi radio is started first in setup. In 1.1.0, a board with no Wi-Fi set started its web server before the network stack existed and crash-looped (`assert failed: xQueueSemaphoreTake ... pxQueue`), and the default ID read P833-000000. Found on the first real board. The PC stand-in now aborts the same way, so the test would catch it. | Bug found on the bench. |
